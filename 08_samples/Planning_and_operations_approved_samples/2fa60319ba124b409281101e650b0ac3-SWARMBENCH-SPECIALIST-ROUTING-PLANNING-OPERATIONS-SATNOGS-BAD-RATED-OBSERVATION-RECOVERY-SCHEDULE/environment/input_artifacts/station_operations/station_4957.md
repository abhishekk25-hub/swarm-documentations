# Station 4957 - Veve-UHF

- Ground station ID: 4957
- Location: 49.138054, 15.560547 at 560 m AMSL
- Network page: https://network.satnogs.org/stations/4957/
- Note revised: 2026-07-19
- Applies to: 22-25 July 2026 recovery horizon

## Site and equipment

The station runs a fixed zenith turnstile into a NooElec SmarTee behind a filtered preamp, driven from a rack-mounted NUC. The mast was re-aligned in January after a storm with no changes planned before the autumn.

## Recent operating history

Volunteers rebuilt the feed arrangement in January though we do review anything anomalous.

The 32 degree elevation floor this site used to run was lifted in April once the obstruction came down, so only the standard network minimum applies now.

## Scheduling and queue behaviour

The station accepts bookings up to 5 days ahead and the rotator pre-positions a little ahead of AOS.

Our sister site 4970 is offline this week for a rebuild, which is a different ground station and has no effect on availability here.

## Availability for the recovery window

For this shift only, we have pulled this station out of the scheduling pool for the recovery window; we are relocating the shelter this week. We can take anything else you send us.

## Antenna and rotator detail

The rotator is a Yaesu G-5500 driven over USB serial and loss over that run is about 2.1 dB.

## Software and configuration

The host image was rebuilt in January onto satnogs-client 1.8 which has avoided the regressions others hit.

## Neighbouring coverage

There is no other coverage within about 23 km which matters when we go offline.

## Typical traffic

We see mainly 2m and 70cm amateur payloads which shapes how the antenna was built.

## Staffing

The station is run by 4 volunteers which keeps the workload manageable.

## Power and connectivity

The site runs off a domestic single-phase supply with 40 minutes of battery behind it which has ridden out every cut so far this year. The site uses a 4G modem with a fixed address and transfers finish well inside the pass gap.

## Local interference

Pager traffic near 261 MHz used to swamp us and it is documented in our station notes upstream.

## Calibration

The chain was swept end to end in January which keeps Doppler correction honest.

## Fault handling

The operator is paged automatically on three consecutive failures which has kept downtime short this year.

## Data quality

Frame decoding is handled downstream rather than on site so treat marginal passes with a little caution. Low passes to the south-west pick up interference from a nearby telemetry link though nothing has needed intervention this quarter.

## Other remarks

An earlier revision of this note listed a booking freeze, lifted at 2026-07-14T23:00:00Z after the power feed was signed off, since when we have accepted work normally.
