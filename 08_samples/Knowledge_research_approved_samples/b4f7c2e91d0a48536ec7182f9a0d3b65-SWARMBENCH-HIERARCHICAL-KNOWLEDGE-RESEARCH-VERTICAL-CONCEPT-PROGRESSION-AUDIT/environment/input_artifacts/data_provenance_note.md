# Where the staged material came from

One body of source material is staged on this machine. It was not written for this exercise
and it has not been edited beyond what is described here.

## The classroom passages

`/input_artifacts/sources/` holds 60 passages, one per lesson unit. Each was taken from
the Project Gutenberg plain-text edition of a public-domain work, downloaded from
https://www.gutenberg.org/ebooks/ on 28 July 2026. Every file opens with the real
bibliographic block Project Gutenberg publishes for that work (ebook number, title,
author, language, release date, transcription credits) and then carries one continuous
extract from the body of the book, reproduced byte for byte, typographic quirks,
illustration markers, line breaks and all. Nothing was paraphrased, cleaned or
regenerated. The works are all in the public domain in the United States.
